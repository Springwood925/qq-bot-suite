# 好感度与批量审核

DSH → 插件 → QQ 机器人套件详情 → 记忆树。

- 人物好感度：显示稳定 QQ、管理员身份、评分和计算依据。`ownerQQ` 对应管理员固定100；其他人0–95。身份取当前配置，不从昵称或聊天自称判断。
- 批量审核：可先点“只看待核实”，勾选单条或“全选当前页待核实”，再选“批量确认”或“批量拒绝/归档”，核对后一次提交。每页20条；服务端一次最多100条，跨会话、旧版本、重复ID、已处理记录均拒绝整批操作。批量审核保留版本与审阅日志，写入失败整批回滚。

## 计算规则

本地确定性计算，不调用聊天模型。每会话独立，不合并其他群/私聊记录。

普通人物：`clamp(50 + 频率加分 + 态度修正, 0, 95)`。

频率：近30天真实收到、明确指向机器人的消息（私聊、@本人、引用本人或提及机器人名字）。同一人每5分钟最多一个有效互动，每日最多12个。加分为 `min(20, round(4 × log2(1 + 有效互动数) + min(6, 活跃天数)))`。普通群聊旁观不加分。

态度：明确感谢、亲善或直接恶意；含糊、引用、疑似反问、否定与混合态度按中性。规则无法可靠理解所有讽刺和复杂语境，不应把评分当作客观人格判断。同一时间段同类态度最多一次，每天最多六次。

有效记忆中，可核对的本人陈述和管理员确认内容可补充近180天明确指向机器人的态度；历史证据按90天时间常数衰减，同一来源只计一次，每天最多六条。不使用他人转述、未经核实推断、无来源旧记忆、已归档/已失效/已遗忘记录。管理员换版继承来源身份用于去重。

正向有效权重为P、负向为N，态度修正为 `round(25P/(P+N+4) - 40N/(P+N+4))`。正负态度独立于频率计分，因此恶意刷屏不会持续刷出亲近关系。

启动时利用已有最近消息与有效记忆建立初始依据，不扫描全部QQ聊天、不调用收费模型。消息来源哈希去重，保存时间、身份和态度值，不另存一份聊天正文。重启不重复加分；遗忘相应记忆会撤销同来源互动，清空会话记忆会设置时间屏障防止旧聊天重放恢复分数。

机器人提示中持续带有管理员真实QQ及固定最高分，也带近期人物的分数与亲疏说明。关闭一般记忆自动注入仍保留管理员身份。评分不授予管理权限，不改变原工具鉴权，不要求机器人在聊天中报分。
