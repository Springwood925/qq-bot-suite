# 记忆树第二、第三阶段

入口：DSH → 插件 → qq-bot-suite → 详情页内的「记忆树」。这是插件原生组件，管理请求通过宿主同源代理，桥的控制台令牌留在宿主端。

## 已实现

- 会话、人物、类型和状态筛选，分页浏览；按当前会话关键词/语义搜索。默认显示当前版本，可单独查看被更正的历史。
- 来源消息引用、原话摘录、图片中文字和不确定项、表达候选的多条样本、完整版本链。
- 修改并说明原因、明确确认、归档、标记完成、两步确认遗忘。管理记录不会自动修改人格文件。
- 关联类型：相关、后续、冲突、目标关联、依赖来源。只有依赖来源会级联撤下派生摘要；普通相关事项不会被误删。相关/后续/目标引用会跟随当前版本，冲突和派生依赖保留原版本供审阅。
- 真实工具成功结果登记为自己的经历；实际读图后保存观察、文字、未确认项和原消息引用。自己的回答或手写声明不能伪造这些来源。不倒填从未实际执行的经历。
- 自己的目标保留状态和下一步，轮换后继续；详情页中的完成/进展/放下同步现有 innerLife 状态。完成标记不证明外部任务成功。遗忘目标也从 innerLife 中移除。
- 群内表达习惯可提出候选，至少3条不同真实消息作来源，始终先待核实；管理员确认后才给当前会话有限参考，仍服从人格，不抄原句、隐私或口头禅，不扩展权限。
- 本地中文嵌入 + IDF 关键词覆盖 + 人物别名 + 一跳关联 + 小幅近期权重。默认排除未核实、已遗忘、被替换和过期节点。先限制会话，再做向量比较，不跨群搜索后补过滤。
- 自动注入保留约900的保守估算预算；本地召回准备最多等待800ms，未就绪继续用关键词。额外深查仍是有上限的工具结果。
- 检索诊断、当前会话索引更新、功能开关、检索次数/耗时/结果字符数；可保存自己的漏检样例并运行前5条命中检验。无样例时不报告成功率。

## 本地模型与费用

固定模型：Xenova/bge-small-zh-v1.5，revision `75c43b069aac4d136ba6bc1122f995fedcfd2781`，q8 ONNX，512维，CLS pooling，最大256 token。模型约24MB；运行库独立安装在 local-memory-runtime，未修改桥主依赖。CPU推理在 worker thread 中执行，禁用远程模型与联网 fetch；聊天和图片摘要不发送给嵌入服务。

没有新增收费 API。DSH 自己提炼候选、调用工具与读取注入内容仍计入原来的对话用量。Codex 读图、生图继续沿用已配置的订阅方式。本次不增加电脑操作能力。

## 数据、遗忘与限制

仍使用 state/memory-tree.sqlite；增加元数据、关系类型、向量、审阅记录、诊断指标和回忆样例等表，不重写旧节点表或强行核实旧便签。升级前请备份自己的数据、配置与代码；SQLite 备份需要包含一致的 WAL 状态，建议使用 SQLite backup API。

纠正会使旧版本退出默认检索，依赖摘要撤为待核实。遗忘同时处理版本、显式依赖摘要、向量、元数据、关联、相应回忆样例及表达样本，并留下防自动重建指纹。原始 QQ 聊天和备份不随之删除。没有显式关联、来源不同的所有同义改写不保证自动识别，管理页可核查处理。

本地小模型仍可能漏掉换说法，或把相近话题召回；相似度不是事实可信度。完整内容和证据类别仍交给对话模型结合当前语境判断。长文本嵌入会截断，关键词与原始消息引用仍可查询；当前向量比较在会话内线性运行，未宣称大规模 ANN 性能或训练了模型权重。

测试使用虚构数据；离线样例结果不能当作实际聊天成功率。原始QQ历史未全量重扫；已存在的图像或工具日志也未反推为新的亲身经历。

## 验证与回退

测试：`node --test scripts/test-memory-tree.mjs scripts/test-memory-phase23.mjs scripts/test-inner-life.mjs scripts/test-prompt-economy.mjs`。模型运行库、模型路径可用 QQ_MEMORY_RUNTIME、QQ_MEMORY_MODEL 指向暂存目录；MCP依赖可用 QQ_BRIDGE_DEPENDENCIES 指向原桥安装。

生产只读验收检查 SQLite 完整性、既有节点未丢失、模型就绪、索引覆盖、插件代理可用、错误/跨会话令牌被拒绝、桥仍正常运行。测试不会向真实QQ发送消息或调用收费模型。

回退前暂停并停止桥接，保存最新一致性备份，再恢复上一版代码。数据库表为增量扩展；不要直接用旧快照覆盖当前数据，以免丢失升级后产生的记忆。

数据库维护和 SQL 缓存说明见 [memory-maintenance.md](memory-maintenance.md)。本地模型安装见 [local-memory-setup.md](local-memory-setup.md)。
