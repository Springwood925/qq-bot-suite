# 小鲸鱼的情绪、边界和目标

2026-10-25。此功能用持久状态维持角色行为的一致性；状态由当前聊天模型结合具体消息语境评估，不按辱骂关键词自动判定。

- 愉快、恼火、低落、好奇、精力：由有依据的新事件改变，随着时间向平常状态恢复。当前恼火程度的半衰期是一小时；针对某人的介意恢复更慢。
- 对人的态度：按来源消息的稳定 QQ ID 保存，区分熟人互损、正常批评与恶意冒犯。对某人的不满不自动复制到其他人；道歉可缓和，不立即抹掉持续冒犯。
- 自己的目标：最多三个进行中，包含具体动机和下一步。默认有效三天，最长一周；只有实际进展才更新，支持完成、放下和过期。目标不会增加工具或执行权限。
- 新工具：`qq_update_inner_state`。`appraisal.sourceSeq` 是收到消息的 `seq`，不是 QQ `messageId`；相同或更旧的来源不会重复加重情绪。更新必须持有当前会话令牌、处于允许范围内且记忆功能已启用。
- 状态保存在 `state/social-v2.json` 各会话的 `innerLife` 内。旧状态会自动补默认值，不回溯历史给群友记过。重启和上下文轮换可保留，管理员重置会话时随该会话清除。
- 每轮自动提供完整的小鲸鱼角色卡和情绪、目标摘要；唤醒摘要省略角色卡、固定规矩已包含的说明。成员记忆只带当前消息窗口的说话者、每人最近三条；话题和未说的想法各最多三项。只裁剪注入，不删除存档；完整内容仍可通过记忆工具及 `qq_get_prompt` 查看。人格覆盖的独立会话不启用情绪功能，各群和私聊状态隔离。
- 上次主动说话后尚无人回应，下一次冷场主动检查不再发起独白；直接收到消息的唤醒不受此限制。表情仍按 `socialV2.sticker` 的 `dueSoft` / `dueHard` 提醒（按各自配置的机器人文字条数），小鲸鱼也适用；严肃或敏感话题、没有贴切表情时可跳过，不强制搞笑收尾。

不新增常驻进程或第二个情绪判定模型。原有聊天模型在有变化时调用工具保存，判断语境和最终说话的质量仍需实际相处观察；离线测试验证机制，不能保证每次语气都符合偏好。

如需关闭，在 `config.json` 的 `socialV2` 下设置 `"innerLife": {"enabled": false}`，保存后按项目配置加载方式生效。记忆工具关闭、当前角色不是“小鲸鱼”、会话使用独立人格覆盖时也不启用。

验证：先对修改过的 JS/MJS 执行 `node --check`，再运行 `node scripts/test-prompt-economy.mjs`、`npm run test:inner-life`、`npm run test-stickers`、`npm run test-wait` 和 `npm run verify:persona`。摘要测试验证原存档不变、未读参与者与目标下一步仍保留；情绪测试使用临时本地接口和真实 MCP stdio 工具，不连接 QQ、不发送测试消息。

修改预设或 MCP 后需要重新加载 DSH；修改桥接源码需要重启桥接。始终先通过语法和相关验证再重启。
